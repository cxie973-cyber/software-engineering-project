# 軟體工程專題｜投稿審查系統

1151 期中個人專題。以作者與編輯兩種角色，完成稿件撰寫、送審、退回修改與通過的流程。

## 快速啟動

需要 **Python 3.10 以上**，僅使用 Python 標準函式庫，不需安裝第三方套件。

1. 按儲存庫的 **Code → Download ZIP**，下載後解壓縮。
2. Windows 使用者雙擊 `啟動系統.bat`；其他系統可在專案資料夾執行：

   ```bash
   python server.py
   ```

3. 開啟 <http://127.0.0.1:8765>。執行期間請保留伺服器視窗。

請透過上述網址操作，前端會呼叫 Python API；直接開啟 `static/index.html` 無法使用完整系統。

## 示範帳號

| 帳號 | 角色 | 密碼 |
|---|---|---|
| `author` | 作者：王小明 | `Demo1234!` |
| `author2` | 作者：林小雨 | `Demo1234!` |
| `editor` | 編輯：陳編輯 | `Demo1234!` |

第一次啟動會建立示範帳號、四篇示範稿件與 SQLite 資料庫。也可以在登入頁面註冊新的作者帳號。示範帳號使用公開的測試密碼，供本機課堂展示使用。

## 作業功能

| 角色 | 功能 |
|---|---|
| 作者 | 查看自己的稿件清單，顯示類別、標題、狀態 |
| 作者 | 新增、編輯與刪除編輯中的稿件 |
| 作者 | 送出稿件，狀態由編輯中改為審查中 |
| 編輯 | 查看待審稿件的作者、類別、標題與內容 |
| 編輯 | 通過稿件，狀態改為已通過 |
| 編輯 | 退回稿件，狀態回到編輯中 |

稿件狀態：**編輯中 → 審查中 → 已通過**；退回則由審查中回到編輯中。

## 延伸功能

- 帳號登入、作者註冊、後端角色與資料存取權限。
- 審查意見，退回時必須填寫修改建議。
- 操作歷史與稿件儲存快照，可查看先前版本的文字。
- 關鍵字搜尋、類別／狀態篩選、排序、統計、字數計算。
- CSV 清單匯出與響應式版面。
- 送審後禁止修改與刪除；版本檢查避免舊頁面覆蓋新內容。

## 展示流程

1. 使用 `author` 登入，新增並修改草稿，接著送出。
2. 登出，改以 `editor` 登入，填寫意見並退回。
3. 改以 `author` 登入，閱讀意見、修改內容，再次送出。
4. 改以 `editor` 登入並通過，查看歷史與狀態變化。
5. 使用 `author2` 登入，確認不同作者的稿件互相隔離。

## 技術與架構

- 前端：HTML、CSS、JavaScript。
- 後端：Python `http.server`、`sqlite3` 與其他標準函式庫。
- 資料儲存：SQLite，首次啟動後產生 `data/submissions.sqlite3`。
- 資料表：`users`、`sessions`、`manuscripts`、`history`。

```text
.
├── server.py          HTTP API、驗證、權限與資料庫
├── 啟動系統.bat       Windows 啟動入口
├── 使用說明.md        完整操作與備份說明
├── static/
│   ├── index.html     頁面結構
│   ├── style.css      樣式與響應式排版
│   └── app.js         表單、清單與審查互動
└── data/              執行時自動產生，不納入版本管理
```

密碼使用含隨機鹽值的 PBKDF2-HMAC-SHA256；登入 cookie 設為 HttpOnly、SameSite=Strict；寫入 API 檢查 CSRF token。SQL 使用參數綁定，稿件操作在交易內檢查作者、角色、狀態與版本。
